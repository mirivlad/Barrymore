# CLAUDE.md

Следуй `AGENTS.md` и `docs/11_ENGINEERING_AUTHORITY.md`.

Используй возможности Claude Code для исследования, subagents и тестирования, но не запускай параллельные изменения без ясных границ.

При противоречии:

1. сформулируй его;
2. определи, затрагивает ли оно пользовательский инвариант;
3. для reversible technical решения создай ADR и продолжай;
4. для изменения продуктового смысла запроси решение.

Первый проход заканчивается реальным audit-only delegation к установленному worker либо честно документированной блокировкой. Mock не считается результатом.
