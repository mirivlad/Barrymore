    Нити

    Нити — внутренняя модель непрерывности Бэрримора. В обычном режиме он ведёт их сам; этот экран остаётся техническим инспектором для отладки, восстановления и редких ручных исправлений.

    Что Бэрримор умеет сам

    Подключить незнакомый инструмент

    Назовите команду — остальное Бэрримор выяснит сам: опросит инструмент безопасными пробами, прочитает его собственную справку и предложит способ запуска. Ни одного флага, которого нет в справке, он не примет.

    Штат

    Обнаружение опрашивает версии и не выполняет платных запросов. Состояние квоты локально не наблюдается и честно показывается как неизвестное.

    Поручить вручную

    Обычно поручение предлагает сам Бэрримор — прямо в разговоре, с уже заполненными целью, причиной и каталогом. Эта форма нужна как технический аварийный путь.

    Без этой отметки исполнитель только читает. С ней он работает в копии каталога, а изменения дойдут до вас только по вашему решению.

    Локальная модель

    Локальная модель — постоянный разговорный и координирующий слой, а не самый сильный работник в доме. Для него обычно полезнее небольшая быстрая модель, которая постоянно помещается в памяти и хорошо соблюдает структурированный контракт; тяжёлую работу Бэрримор может поручить персоналу.

      Сеть персонала

      Внешний персонал может работать через отдельный прокси. Эта настройка не меняет сеть самого Бэрримора и локальной модели. Сейчас её можно задать в settings.json полем worker_proxy или флагом -worker-proxy; управление отсюда будет добавлено отдельным безопасным API-срезом.

      Чем можно платить

      Политика стоимости решает, какие модели достанутся исполнителям. Действует сразу; уже подтверждённые поручения сохраняют выбранную им модель — подтверждали именно её.
