# ADR 0013: Повседневная работа идёт на бесплатных моделях, специалисты — по вызову

Status: Accepted
Date: 2026-08-05

## Context

Первый проход строился вокруг codex как основного исполнителя. Владелец уточнил
расстановку: codex и Claude Code — мастера по вызову для трудных задач, а
повседневную работу должны вести opencode и hermes на бесплатных моделях.

Это подтвердилось и практикой: квота codex исчерпалась на первом же реальном
поручении, тогда как opencode предлагает 20 бесплатных моделей (7 собственных
и 13 через OpenRouter), а hermes уже настроен на бесплатную модель.

## Decision

### Класс исполнителя

Каждый worker относится к одному из классов:

| Класс | Кто | Когда привлекается |
|---|---|---|
| `routine` | opencode, hermes | повседневно, по умолчанию |
| `specialist` | codex, Claude Code | по трудной задаче или ручному выбору владельца |

При обычной задаче специалист получает штраф к оценке; при политике «только
бесплатные» он не рассматривается вовсе. Ручной выбор владельца и пометка
задачи как трудной снимают запрет — но это осознанное решение, а не умолчание.

### Стоимость определяется до запуска

Бесплатность модели решается **до** её использования, по пометке провайдера в
названии (`-free`, `:free`, локальные модели). Другого бесплатного способа
узнать цену заранее нет. Модель без явной пометки бесплатной не считается:
молчание провайдера — не разрешение тратить деньги владельца.

### Списание — признак нарушения, а не источник цены

Фактическое списание никогда не используется, чтобы «узнать» стоимость: если
списание произошло, деньги уже потрачены. Оно используется как страховка.

На бесплатной модели создаётся ожидание `worker_run.cost_policy` с пределом 0.
Любое ненулевое списание означает, что провайдер изменил условия:

1. создаётся критическое расхождение;
2. локальная реакция `run.stop_on_charge` немедленно прекращает запуск;
3. модель навсегда помечается платной;
4. поручение переходит в `failed` с объяснением.

Отметка о списании постоянна и переживает обновление каталога: провайдер может
вернуть в название пометку «free», но память о списании не стирается.

### Каталог моделей — наблюдение, а не константа

Состав бесплатных моделей меняется. Поэтому:

- каталог перечитывается целиком, исчезнувшие модели удаляются;
- у каталога есть срок годности (`ModelCatalogTTL`, 6 часов), устаревший
  каталог понижает оценку исполнителя и говорит об этом в причинах;
- отметки о списаниях переносятся на обновлённый список.

### Политика стоимости настраивается

`-model-policy free | prefer-free | any`. Умолчание — `free`.

## Consequences

- opencode и hermes получают полноценные адаптеры с запуском и разбором вывода;
- манифестные записи для них удалены: обнаружение без запуска больше не нужно;
- у `RunPlan` появился упорядоченный список монтирований: порядок семантичен,
  одному инструменту нужен файл только для чтения внутри писчего каталога,
  другому — писчий подкаталог внутри каталога только для чтения;
- `WorkOrder` хранит выбранную модель, её стоимость и обоснование выбора;
- подтверждение владельца показывает модель и стоимость до запуска;
- у hermes нет неинтерактивного списка моделей — Бэрримор берёт настроенную
  модель из `hermes status` и честно помечает ограничение источника.
