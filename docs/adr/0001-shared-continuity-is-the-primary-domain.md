# ADR 0001: Общая непрерывность является главным доменом

Status: Accepted

## Context

Путь универсального agent harness почти неизбежно создаёт ещё один OpenCode/Claude Code-подобный инструмент. Уникальная ценность находится в общей истории человека и постоянного помощника.

## Decision

Главной сущностью является Thread, а не Task или Chat. Система хранит позиции, решения, вопросы, обязательства, shared history, поручения и результаты.

## Consequences

Chat messages не являются каноническим состоянием; memory/thread projections обязательны с foundation; delegation является подсистемой; UI строится вокруг нитей; coding agent не становится центром продукта.
